# Profiles

This directory is reserved for deliberately authored Profile records governed by `schemas/profile.schema.json`. No personal preferences are fabricated as examples in Phase 2. Profiles reference catalog IDs through default and excluded capability lists; they do not duplicate capability definitions or authorize installation.

Phase 3 adds `personal.yaml` with empty defaults and exclusions, explicitly unconfigured. Composer reads those two lists; other preferences do not yet drive rules.
