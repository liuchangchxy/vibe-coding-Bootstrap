# Experiences

This directory contains human-curated Experience records governed by `schemas/experience.schema.json`. See [the lifecycle](../docs/experience-lifecycle.md) for states and [governance](../docs/experience-governance.md) for promotion boundaries. Records are grouped in `raw/`, `candidate/`, `verified/`, `rejected/`, and `archived/`; these folders do not trigger automation. Examples illustrate distinct lifecycle outcomes and are explicitly illustrative, not claims about actual projects. Keep private project knowledge in its source project and reference it without copying it here.
